# Project site template (custom)

A one-page project write-up in plain HTML and CSS, published free with GitHub Pages. Edit anything you like.

## Use it

1. Click **Use this template → Create a new repository**. Give it a short name like `smart-plant-pot` and make it **Public**.
2. Open `index.html`, click the pencil icon, and replace everything in `[square brackets]`. Commit your changes.
3. Upload photos to the `images` folder (**Add file → Upload files**), then change `images/cover.svg` in `index.html` to your file names. Keep each photo under 1 MB.
4. To embed your demo video, replace `VIDEO_ID` with the ID from your YouTube link (the part after `v=`).
5. Change colors and fonts at the top of `style.css`.
6. Go to **Settings → Pages**, choose **Deploy from a branch**, pick `main` and `/ (root)`, and click **Save**.

Your site will be live at `https://your-username.github.io/your-repo-name/` in a minute or two.
